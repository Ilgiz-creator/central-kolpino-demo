# Central · Колпино

Приватный концепт сайта для кандидата **C-067**, Яндекс ID `133533991057`, 2ГИС ID `70000001048121717`.

Статическая HTML/CSS страница без зависимостей и клиентского JavaScript. Исходный production-каталог `dist/` хранится в Git и готов к раздаче Nginx/Caddy/статическим хостингом. Никакой серверной сборки или установки зависимостей не требуется.

## Запуск и production-проверка

```sh
node validate.mjs
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist
```

`validate.mjs` проверяет наличие входного файла, ресурсов, внутренних якорей, адресов ссылок, согласованность телефона и маркировку демо. Визуальная проверка описана в `QA.md`.
