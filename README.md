# Central · Колпино

Открытый демонстрационный концепт сайта для кандидата **C-067**, Яндекс ID `133533991057`, 2ГИС ID `70000001048121717`.

Статическая HTML/CSS страница без зависимостей, с небольшим клиентским JavaScript. Исходный production-каталог `dist/` хранится в Git и готов к раздаче Nginx/Caddy/статическим хостингом. Никакой серверной сборки или установки зависимостей не требуется.

## Запуск и production-проверка

```sh
node validate.mjs
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist
```

`validate.mjs` проверяет наличие входного файла, ресурсов, внутренних якорей, адресов ссылок, согласованность телефона и маркировку демо. Визуальная проверка описана в `QA.md`.

## Материалы

`dist/assets/central-hero.webp` — оригинальная иллюстрация, созданная встроенным ImageGen и оптимизированная в WebP. Не изображает реальное кафе. Точный prompt в `IMAGE-PROMPT.md`. Чужие фотографии, логотипы и тексты отзывов не включены. Открытая публикация оригинальных материалов разрешена Ильгизом 11.09.2026; официальный запуск требует согласования с бизнесом.

Кнопки открывают телефон, Telegram, WhatsApp и маршрут. Форма составляет сообщение локально и открывает проверенный WhatsApp; автоматически ничего не отправляется.
